# Visual Showcase using TouchDesigner

This project demonstrates three unique art pieces that can be displayed by pressing keys `3`, `4`, and `5` in TouchDesigner. The works utilize concepts from a previous project, incorporating diverse visual styles to create a cohesive experience. These visuals are adaptable and can be used in various setups, including dome environments.

## Dome Adaptability

Although these visuals were not presented in the dome during this demonstration, they are designed to be compatible with such environments. They can be seamlessly integrated into immersive setups for enhanced viewing experiences.

---

### How to Use

1. Open the `.tox` file in TouchDesigner.
2. Press keys `3`, `4`, or `5` to display the corresponding visual.
3. Enjoy the unique visual experience!
