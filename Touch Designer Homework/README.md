# TouchDesigner Tutorial Project

This project follows an animated noise tutorial created by [Simon Alexander-Adams](https://www.youtube.com/@polyhop). The tutorial can be found [here](https://www.youtube.com/watch?v=dwh5CS_0EDs&ab_channel=SimonAlexander-Adams).

## About the Project

I came across this tutorial and noticed that it was more intermediate-level, so I decided to challenge myself as a beginner in TouchDesigner. Although I am more familiar with other tools, this was a great opportunity to explore and learn.

I successfully completed the tutorial while making some personal adjustments, such as changing the colors and modifying the noise style to suit my preferences.
