# Gen Art Recreation Homework

The project I recreated was made by **Patricio Gonzalez Vivo**, a designer, artist, and programmer known for his work exploring computational art and creative coding.  

In this piece, it showcases the idea of using **Perlin noise**, which is created via this concept. This artist showcases this artwork alongside his work on the **Perlin Noise 2016 series**.
