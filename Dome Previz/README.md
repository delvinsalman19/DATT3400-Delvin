# Dome Visualization Project

This project showcases three unique types of visuals designed for a dome environment. The visuals leverage the concepts of noise, rotation, speed, feedback loops, and dynamic color movements. The aim was to create interconnected visuals emphasizing movement and noise.

## Features
- **Noise and Movement:** The visuals utilize noise functions to generate organic motion and patterns.
- **Dynamic Feedback Loops:** Each visual has unique feedback effects, creating depth and complexity.
- **Color and Speed Variations:** The visuals display vibrant, shifting colors and adjustable speeds to enhance their impact.
- **Switchable Visuals:** A built-in switch allows seamless toggling between three visual styles using an index (0-2).

## Usage
The visuals can be toggled by switching the index value between 0, 1, and 2. Each index corresponds to a unique visual style:
- **Index 0:** Visual Style 1
- **Index 1:** Visual Style 2
- **Index 2:** Visual Style 3

## Technical Notes
This project was created with an emphasis on:
- Integrating advanced visual effects with movement and noise-based algorithms.
- Ensuring seamless transitions and cohesive design across different visual styles.
- Making use of the dome aspect.
