# Visual Touch

**Visual Touch** is an interactive generative artwork that allows users to create unique and captivating visuals through mouse interactions. The project includes a variety of dynamic features, making it visually engaging and interactive. 

## Features

- **Interactive Visuals**: Users can interact with the artwork using their mouse to generate unique visuals.
- **Sound-Responsive Particles**: Particles react to sound inputs such as music, voice, or any sound source, based on volume and intensity.
- **Variety of Patterns**: The project features over 25 unique patterns, utilizing mathematical variations to create stunning movements and styles.
- **Customization Options**:
  - Adjust movement speed, size, colors, and shapes.
  - Edit particle cycles and other parameters for personalized visuals.
- **Auto Mouse Functionality**: An automated mode generates visuals without user interaction, adding versatility to the project.

## Concept

The core idea of **Visual Touch** is to leverage JavaScript and p5.js to produce engaging, interactive designs. The project combines concepts like particles, sound interaction, and mathematical variations to create visually striking and dynamic outputs.

## Project Highlights

- **Interactive & Automated Modes**: Offers both user-driven and auto-generated visual experiences.
- **Sound Integration**: Visuals dynamically respond to sound, enhancing the sensory experience.
- **Customization & Variety**: Extensive options for visual customization and a wide range of patterns.

## How to Use

1. **Interact with the Artwork**:
   - Use your mouse to explore and create visuals.
   - Play music or use any sound source to see how particles react dynamically.
2. **Enable Auto Mode**:
   - Activate the "Auto Mouse" feature to let the artwork play itself, showcasing its full range of possibilities.
